# SmartFace TimeLine

A customizable digital watchface for **Pebble Time 2** (`emery`, 200x228 color).

Features: three languages (EN/RU/DE), day/night themes with an automatic
night mode, date formats, battery/Bluetooth indicators, hourly and event
vibration, and two configurable info strings — plain text or a URL whose
first line is fetched from the phone.

## Layout

```
+------------------------------------------------+
| (bt)  connected text            battery%  (bat)|
|                                                |
|                  weekday / date line           |
|                     12:34                      |
|                  date line / weekday           |
|               top additional string            |
|              bottom additional string          |
+------------------------------------------------+
```

## Project layout

| Path                | Contents                                              |
|---------------------|-------------------------------------------------------|
| `src/c/`            | watchapp C sources (`app.c` is the entry point)       |
| `src/pkjs/`         | PebbleKit JS (`pebble-js-app.js`, copied verbatim)    |
| `config/index.html` | self-contained configuration page — must be hosted    |
| `resources/`        | fonts and icons; icons are generated by `tools/`      |
| `tools/`            | asset generator (`generate_icons.py`, needs Pillow)   |

## Building

The build runs in Docker (Rebble SDK 4.9.169, pebble-tool 5.x):

```sh
docker create --name pebble-build --security-opt apparmor=unconfined \
  -v "$PWD":/project -w /project \
  gregolsky/pebble-sdk:sdk-4.9.169 sleep infinity

docker exec -u root pebble-build pebble build
```

The result is `build/project.pbw`. Install it to a paired watch with
`pebble install --phone <PHONE_IP>` or by dropping the `.pbw` onto a
Rebble-enabled phone app.

## Configuration page (hosting required)

Pebble webviews can only load `http(s)` pages, so the settings page must be
hosted. The page lives in `config/index.html` and is fully self-contained
(no external assets).

To publish it via GitHub Pages:

1. Push this repository to GitHub.
2. Repository **Settings → Pages → Source: Deploy from a branch**
   (`main` / `docs` or root).
3. The page becomes `https://<user>.github.io/<repo>/config/index.html`.
4. Update `CONFIG_URL` in `src/pkjs/pebble-js-app.js` to that address and
   rebuild.

The page receives the current settings as a `?state=<urlencoded json>` query
parameter and returns the edited dictionary through the standard
`pebblejs://close#<json>` protocol.

## Notes for upgraders from the 2014 release

* The app UUID and all persistent-storage keys are unchanged, so existing
  users keep their configuration after the update.
* Night-mode start/end times are stored as *minutes since midnight*. Old
  out-of-range values are reset to the defaults (22:00 / 07:00); values that
  were valid minutes keep working.
* The unread-messages counter and its icon never worked in the old release
  and have been removed together with the dead code.
